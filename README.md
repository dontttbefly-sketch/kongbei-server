# 空杯记账 · 服务端源码

这里是「空杯记账」线上版（[my.kongbei.xyz](https://my.kongbei.xyz)）**服务端代码的原样镜像**。

放出来的目的只有一个：**让你能自己核对——你的账，到底有没有被存下来。**

---

## 结论

你的每一笔账，服务器拿到之后只做一件事：**写进你自己的飞书多维表格**，然后把结果返回。服务器上不留任何一笔账的副本。

这不是一句承诺，是可以查的。

## 怎么自己查（三条命令）

```bash
git clone <本仓库地址> && cd kongbei-server

# 1) 服务端所有的存储写入点。看完你会发现只有 4 类，没有一类是账单
grep -rn "storage()\.set" server/code/ --include=*.js | grep -v test

# 2) 写飞书的地方——账单唯一的去处
grep -rn "createRecord" server/code/ --include=*.js | grep -v test

# 3) 有没有偷偷写文件/写数据库
grep -rn "writeFile\|fs\.write\|INSERT INTO\|mongoose\|sequelize" server/code/ --include=*.js
# ↑ 最后这条应该什么都搜不到（服务端是零依赖的，没有数据库驱动）
```

## 服务器上到底存了什么

| 存在哪 | 存什么 |
|---|---|
| **你的飞书多维表格** | 全部账单：金额、类目、备注、日期 |
| 服务器（Redis） | 只有 4 类，见下表 |

| # | 存的东西 | 含账单吗 | 多久清掉 |
|---|---|---|---|
| 1 | 账号记录：加密后的应用凭证、到期时间、账本 ID | 不含 | 你注销才删 |
| 2 | 激活码（谁用过） | 不含 | 永久 |
| 3 | 面容 ID 的设备索引（这台设备能登哪个账号） | 不含 | 你关掉就删 |
| 4 | 备注提醒的去重时间戳 | 不含 | 最快 1 小时、最长 7 天 |

**没有第 5 类。**

## 不用读代码也能验的三个实验

| 实验 | 怎么做 | 会看到什么 |
|---|---|---|
| ① 拔掉钥匙 | 到飞书里删掉「空杯记账」这个应用 → 回看板刷新 | **立刻打不开**。因为我手里只有你的钥匙，没有你的账 |
| ② 改源头 | 直接在飞书表里改某一笔的金额 → 回看板刷新 | **数字跟着变**。服务器没有自己的版本，每次都去读你的表 |
| ③ 看流向 | 浏览器开发者工具 → 网络 | 每一笔数据都从飞书接口回来，服务器只转发一次 |

三个实验都不用懂技术，做完你心里就有数了。
